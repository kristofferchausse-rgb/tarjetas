Arquitectura Técnica & Despliegue

Especificación vCard 3.0, JSON Schema y Configuración Google Cloud

Estructura de Datos del Perfil (Active Participant Schema):

Validado contra TypeScript Interface 








            Las tarjetas digitales generan dinámicamente un archivo con extensión .vcf codificado en UTF-8. Este formato es compatible de forma nativa con las agendas de iOS (Contactos de Apple), Android (Google Contacts) y Microsoft Outlook.
          








Reglas de Integridad para México (+52):


    

  • Formato telefónico E.164 obligatorio: +5255XXXXXXXX o +5281XXXXXXXX.
    • 

  • Soporte de caracteres especiales y acentos (Á, É, Í, Ó, Ú, Ñ) mediante escape UTF-8 nativo.
    • 

  • Inclusión de URL estable para re-sincronización con el directorio del evento.
    • 










Guía de Despliegue en Google Cloud Platform



            Arquitectura serverless optimizada para más de 100,000 escaneos simultáneos en salones de eventos sin sobrecostos de servidor:
          





1. Almacenamiento Estático y CDN

Bucket en Google Cloud Storage configurado como sitio web público con Cloud CDN activado para almacenamiento en caché perimetral en Monterrey y CDMX (latencia menor a 15ms).





2. Cloud Run (Generador Dinámico de vCards & QR)

Microservicio ligero en Node.js empaquetado en contenedor Docker mínimo (Distroless). Escala automáticamente a cero instancias cuando no hay tráfico.





3. Cloud DNS & SSL Administrado

Certificados TLS automáticos con Google Certificate Manager enlazados al dominio canónico redconecta.mx.
